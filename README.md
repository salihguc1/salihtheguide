# salihtheguide.com

Website of Muhammed Salih Güç, tour guide in Istanbul.

## How to update
- Edit `index.html` (or ask Claude for a new version) and upload it here with **Add file → Upload files**.
- Settings for WhatsApp and the tip link are at the top of the `<script>` section, under `CONFIG`.
- Recommendations are in the `RECS` list, tours in `TOURS`, FAQ in `FAQ`.

## Hosting
GitHub Pages, branch `main`, folder `/ (root)`. The `CNAME` file holds the custom domain.
